# Chrome Extension Installation and Usage Instructions

## Installation
1. Download the latest version of the Chrome extension from the releases section of the repository.
2. Open Chrome and navigate to `chrome://extensions/`.
3. Enable "Developer mode" using the toggle switch in the top right corner.
4. Click on the "Load unpacked" button and select the folder containing the downloaded extension files.

## Usage
1. After installing, the extension icon will appear in your Chrome toolbar.
2. Click on the icon to open the extension interface.
3. Follow the on-screen instructions to configure settings and start using the extension.
